# Contributing to Chrome History Cleaner

Open pull requests against [Arsey/chrome-history-cleaner](https://github.com/Arsey/chrome-history-cleaner). Tell us what you changed, why, and how you tested it. Run `npm test`. Use made-up URLs and rules for browser tests and examples. See [SECURITY.md](SECURITY.md) for private security reports.
