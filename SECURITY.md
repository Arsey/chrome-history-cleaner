# Reporting a security issue

Use the [private support form](https://docs.google.com/forms/d/e/1FAIpQLSfs9_6vbZzlLaJO2r20FfiTOpgwmDCH8UifT05wKkjZPyWcPw/viewform) and start your message with “Security report”. Include the extension version, Chrome version, what can go wrong, and how to reproduce it. Include an email address if you want a reply.

Use synthetic URLs and rules in any examples. Keep real browsing history, rule exports, credentials and other private information out of the report. Please report the issue privately before posting details in a public issue.
