# Chrome History Cleaner

## Store description

Remove entries from Chrome history by keyword or domain. A keyword can match the page address, the title, or both. Use Protect to make exceptions to a removal rule.

Click Preview matches to check what will be removed. You can run a cleanup yourself, use a default interval, or set a custom interval for each removal rule. Automatic cleanup is off when you install the extension. A cleanup removes every visit to a matching address.

You can add as many rules as you need and back them up as a JSON file. The extension is free and checks your history on your device.

## Privacy practices: permission fields

- **history**: Read page URLs, titles, and visit times to find matches for rules the user creates. Remove matching URLs during user-authorized cleanup. Browsing history is processed on the device.
- **storage**: Save rules, schedules, and cleanup results on the device. Hold preview URLs in Chrome session storage until the preview is replaced or invalidated, or Chrome clears the session.
- **alarms**: Schedule automatic cleanup at intervals the user chooses. Automatic cleanup is off by default.
- **unlimitedStorage**: Support large user-defined rule sets in local storage without a fixed storage quota.
- **Remote code**: No. All executable code is packaged in the ZIP.
